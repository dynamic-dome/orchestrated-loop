# Daily Pulse

**Daily Pulse**: Ein wiederkehrender Ideen- und Projektimpuls. Aus kurzen Chats entstehen strukturierte Downloads, Beispiele, Repos oder Integrationsvorlagen.

**Claude Code**: Builder-Werkzeug für Codeanalyse, Implementierung, Refactoring und Tests in einem bestehenden Projekt. In diesem Kit erhält Claude Code klare Handoff-Dateien, Prompts und Integrationsregeln.

**NotebookLM**: Researcher-Werkzeug für quellenbasiertes Fragen und Zusammenfassen. In diesem Kit wird NotebookLM über Handoff-Dateien eingebunden, damit Quellenantworten nachvollziehbar bleiben.

**Researcher**: Die Rolle, die Wissenslücken beantwortet, Quellen zitiert und offene Fragen zurückgibt.

## Download-Standard

Für Daily-Pulse-ZIPs gelten deutsche Dokumentation, Voraussetzungen, Claude-Code-Auftrag, Tests oder Smoke-Checks und eine klare Integrationsbeschreibung als Standard.
