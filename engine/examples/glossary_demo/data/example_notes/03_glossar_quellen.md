# Glossar-Use-Case

**Markdown-Glossar**: Ein automatisch erzeugtes Begriffsinventar aus Notizen, Spezifikationen oder Projektdateien.

**RAG**: Retrieval-Augmented Generation. Ein Verfahren, bei dem relevante Quellenabschnitte gesucht und einem Sprachmodell als Kontext gegeben werden.

**CLI**: Command Line Interface. Eine textbasierte Bedienoberfläche, die sich gut für Tests, CI/CD und lokale Automatisierung eignet.

**RESULTS.json**: Maschinenlesbares Ergebnisprotokoll des Loops. Claude Code kann diese Datei auswerten, um den nächsten Integrationsschritt zu planen.

**Handoff**: Übergabeformat zwischen Tools, wenn kein direkter API-Adapter verwendet wird. Beispiele sind NotebookLM-Fragen oder Claude-Code-Aufträge als Markdown-Dateien.
