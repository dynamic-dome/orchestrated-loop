# Agentic OS

**Agentic OS**: Ein persönliches Arbeits- und Automationssystem, das Ziele, Aufgaben, Quellen, Agenten und Ergebnisse in wiederholbaren Schleifen organisiert.

**Orchestrator**: Die steuernde Rolle im Loop. Sie erstellt den Plan, verteilt Aufgaben, sammelt Ergebnisse und entscheidet über die nächste Iteration.

**Builder**: Die Rolle, die konkrete Artefakte erzeugt. In diesem Kit ist das zuerst ein Python-Kommando, später kann Claude Code Codeänderungen, Tests und Reports ausführen.

**Judge**: Die Bewertungsrolle. Sie prüft Muss-Kriterien, Artefakte, Robustheit und Dokumentation anhand einer festen Checkliste.

**Quality Gate**: Eine messbare Schwelle, die festlegt, wann eine Iteration ausreichend gut ist. Beispiel: Overall-Score mindestens 0.85.

## DoMe Loop

Der DoMe Loop folgt dem Muster Planen, Ausführen, Reflektieren und Verbessern. Für Daily-Pulse-Ideen ist er hilfreich, weil jede Idee schnell als kleiner Prototyp mit Ergebnissen und Entscheidungshistorie sichtbar wird.
